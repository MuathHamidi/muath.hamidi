How Markdown Forge Works

Every button, explained with an example.

File Operations

Import

Load a .md, .txt, or previously-exported .html file into the editor. Importing an exported .html automatically extracts its original Markdown source rather than the rendered HTML.

Export .MD

Downloads exactly what's in the editor as a plain document.md file — nothing added, nothing rendered.

Export .HTML

Renders your current Markdown into a complete, standalone HTML document (with its own Copy / Print / Theme / Export buttons) that anyone can open in a browser, with no need for this app.

Print

Opens your browser's print dialog using a clean, light-background layout optimized for paper/PDF, regardless of which theme you're currently using on screen.

View Controls

Focus Preview

Hides the editor panel so the preview takes the full window width; click again ("Show Editor") to restore the split view.

Theme toggle (sun/moon icon)

Switches the whole app between dark and light mode; your choice is remembered for next time.

Drag divider

Click and drag the thin bar between editor and preview to resize the two panels; double-click it to reset to a 50/50 split.

Formatting Toolbar

Each button wraps your current text selection, or inserts a starting point if nothing is selected.

Bold

Wraps selection in **text** → renders as bold text.

Italic

Wraps selection in *text* → renders as italic text.

Strikethrough

Wraps selection in ~~text~~ → renders with a line through it.

Heading

Adds ### before the line → renders as a heading.

Quote

Adds > before the line → renders as a blockquote.

Inline Code

Wraps selection in single backticks → renders as code text.

Bullet List

Adds - before the line to start an unordered list item.

Link

Wraps selection as [text](https://) — fill in the URL after inserting.

Image

Inserts ![alt text](image.jpg) — replace with a real image URL.

Table

Inserts a starter 2-column table template you can extend with more | columns/rows.

Task List

Inserts - [ ] for an unchecked to-do item; change to - [x] to mark it done.

Mermaid Diagram

Inserts a starter fenced \`\`\`mermaid block that renders as a live flowchart in the preview.

Clear All

Empties the editor completely. This cannot be undone once the page auto-saves, so use with care.

Preview Panel

Floating Copy button (bottom-right of preview)

Copies your raw Markdown source to the clipboard (not the rendered HTML).

Copy button on individual code blocks

Appears on hover over any fenced code block, and copies just that block's contents.

Scroll sync

Scrolling either the editor or the preview moves the other panel proportionally, so they stay roughly aligned.

Live rendering

Markdown, math ($...$ and $$...$$), and \`\`\`mermaid diagrams all re-render automatically as you type — no manual "refresh" step.

Status Bar

Word count / char count

Live counts of your document as you type.

Reading time

Estimated at 200 words per minute.

Auto-Saved

A green checkmark that briefly appears whenever your work is saved to this browser's local storage, so a page refresh won't lose your content.
